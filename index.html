Como preparar a pele para uma maquiagem perfeita

Por: Mariana dos Santos

O segredo de uma maquiagem duradoura e sem efeito 'craquelado' está na preparação da pele. Antes de aplicar a base, siga estes passos essenciais:

  • Limpeza: Lave o rosto com um sabonete específico para seu tipo de pele.
  • Hidratação: Aplique um bom hidratante para reter a água na pele.
  • Proteção/Primer: Use protetor solar no dia a dia ou um primer para suavizar os poros.

Guia essencial de pincéis para quem está começando

Por: Mariana dos Santos

Com tantos modelos no mercado, é fácil se confundir. Para montar o seu primeiro kit, você só precisa destes pincéis básicos:

  • Pincel Kabuki ou Esponja: Perfeitos para aplicar base de forma uniforme.
  • Pincel Fofo para Pó: Ideal para selar a pele sem acumular produto.
  • Pincel Chanfrado: Excelente para aplicar blush ou contorno no rosto.
  • Pincel de Esfumar: Indispensável para deixar a sombra nos olhos bem acabada.
